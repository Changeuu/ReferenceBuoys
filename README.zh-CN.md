# 引用浮标 · Reference Buoys

[English](README.md) | **简体中文**

**阅读公式密集的笔记，也能随时找回阅读位置。**

原有 `[[#章节]]`、`[[笔记#章节]]` 也支持预览和跨笔记返回。

在 Obsidian 中，用 `@{1.13a}` 这样的简单标记引用同篇笔记中的公式、图片、表格和其他内容。桌面端悬停即可预览，固定多个窗口可以持续对照；手机端点击打开预览，收起后只留一个小标签。点击跳转后，用可堆叠的返回浮标找回出发处。

专为**实时预览**设计，保留你手动规划的编号，支持 `1.13a`、`1.13b` 等子标号。

**0.1.9 试用版 · Windows + Android（试用）· Obsidian 1.8.0 或更新版本**

## 安装

从 [Releases](https://github.com/Changeuu/ReferenceBuoys/releases) 下载 `reference-buoys-版本号.zip`。不要下载 GitHub 自动提供的 “Source code” 压缩包。

1. 解压发布包，把里面的 **`reference-buoys` 文件夹**复制到笔记库的 `.obsidian/plugins/` 下。
2. 最终应当能看到以下三个文件，中间不要多套一层同名文件夹：

   ```text
   你的笔记库/
   └─ .obsidian/
      └─ plugins/
         └─ reference-buoys/
            ├─ main.js
            ├─ manifest.json
            └─ styles.css
   ```

3. 在 Obsidian 的「设置 → 第三方插件」中启用 **引用浮标 · Reference Buoys**。如果列表还没刷新，重启一次 Obsidian。
4. 将发布包里的「示例笔记」文件夹复制到你的笔记库，打开其中的 `引用浮标体验.md`，切到**实时预览**。

安装包已经构建完成，不需要安装 Node.js，不需要运行任何脚本。尚未上架社区插件市场。

**从旧版升级：** 先禁用插件，将新版 `reference-buoys` 内的 `main.js`、`manifest.json`、`styles.css` 覆盖到原插件目录，再重新启用。原来的 `data.json` 设置文件可以保留。

## 引用语法速查

| 内容 | 原文处的编号标记 | 正文中的引用 |
| --- | --- | --- |
| 公式 | 独立公式中的 `\tag{1.13a}` | `@{1.13a}` |
| 图片 | 图片下方的 `@#fig{1.3}` | `@fig{1.3}` |
| 表格 | 表格下方的 `@#tab{1.3}` | `@tab{1.3}` |
| 其他内容 | 内容块下方的 `@#add{A.1}` | `@add{A.1}` |
| 定义 | 内容块下方的 `@#def{1.1.1}` | `@def{1.1.1}` |
| 定理 | 内容块下方的 `@#thm{1.1.1}` | `@thm{1.1.1}` |

各类编号相互独立，可以使用相同的号码。

## 章节引用与跨笔记返回

继续使用 Obsidian 原有的双链写法：

```markdown
[[#能量]]
[[力学笔记#能量]]
[[力学笔记#能量|能量讨论]]
```

在**实时预览**和**阅读视图**中，悬停预览章节，点击跳转并留下返回浮标。手机端先点击打开预览，再点面板中的「跳转」。预览包含该标题和下属子章节，到下一个同级或更高级标题前结束；长章节可在窗内滚动，图片和嵌入内容按目标笔记的路径解析。

- 原有链接、显示文字和 Markdown 保持原样，无需转换或额外编号。
- 独立开关「**章节链接预览与返回**」默认开启。
- 普通点击使用插件；Ctrl/Meta/Shift/Alt 点击及鼠标中键保留 Obsidian 原有行为，不额外创建浮标。把光标移进链接即可编辑原文。
- 找不到笔记或章节时显示提示，不创建新笔记或无效浮标。重名章节沿用 Obsidian 的标题定位规则。
- 浮标在切换笔记后继续显示，因此 A → B → C 后可依次返回 B、A，也可直接点击较早的浮标；每次只移除用掉的那一条。
- 优先返回出发时的面板；原面板已关闭时使用可用面板。桌面跨笔记浮标显示 `↩` 和出发笔记名；手机只保留小巧的 `↩` 标签。
- 本功能处理正文中的章节双链。普通 `[[笔记]]`、`[[#^块编号]]`、嵌入内容和源码模式保持原有行为；`@{...}` 这类编号引用仍限定在同一篇笔记。

可用示例文件夹中的 `章节引用体验.md` 及两篇配套笔记试用。如果其他插件也接管章节悬停，可通过独立开关选择使用哪套预览。

## 公式引用

直接使用你手动写下的编号：

```markdown
$$
p = mv \tag{1.13a}
$$

$$
E_k = \frac12 mv^2 \tag{1.13b}
$$

将 @{1.13a} 代入 @{1.13b}。
```

正文显示为「将（式 1.13a）代入（式 1.13b）」。支持 `1.13a`、`1.13b`、`A.1` 等完整编号，保留大小写。

- **编号始终由你管理。** 插件不会自动编号、改号或添加 `eq:xxxx`、块 ID 等额外标识。
- 同一个公式块含多个 `\tag` 时，预览突出被引用的那一行；编号之间有连续无编号行时也能正确对应。
- 较长的 `align` / `align*` 递等式（至少五行）默认聚焦引用段：保留起始行的左侧表达式，以及被引用行和它之前连续的无编号推导行。省略的位置会明确标出；最后一个编号之后的续行也会保留。
- 点击「展开完整公式组」查看全过程，再点「聚焦引用」恢复节选。短公式组、包含多个独立等式或无法可靠截取的结构保留完整内容，嵌套的 `cases`、`aligned` 不会被拆开。可用示例文件夹中的「多编号递等式体验.md」试用。
- 公式使用 Obsidian 自身的 MathJax 渲染；语法必须是 MathJax 支持的 LaTeX。
- 手动修改编号后，对应引用也需要由你修改。未找到的引用会用虚线提示。

## 图片和表格

**有 `#` 表示定义编号，没有 `#` 表示引用。** 图片、表格和公式的编号相互独立。

`fig` 是 figure 的缩写，`tab` 是 table 的缩写。正文中仍显示「（图 1.3）」「（表 1.3）」。

```markdown
![[示意图.png]]

@#fig{1.3} 图片说明，可省略。

参见 @fig{1.3}。
```

也支持标准 Markdown 图片 `![说明](assets/示意图.png)`。

```markdown
| 物理量 | 单位 |
| --- | --- |
| 质量 | kg |
| 速度 | m/s |

@#tab{1.3} 表格说明，可省略。

将 @tab{1.3} 中的数据代入 @{1.13a}。
```

**编号标记必须另起一行，紧跟完整图片或表格。** 中间可以空行，但不能插入其他正文。图片应单独占一段，表格采用标准 Markdown 表格。子标号如 `@fig{1.3b}` 同样支持。

## 通用附注

用 `add`（addons 的缩写）引用其他内容，渲染为「（附 1.3）」。它与公式、图、表的编号相互独立，也支持 `1.13a` 等子标号。

```markdown
这里是需要反复查看的一段说明，可以含公式 $v \ll c$。

@#add{1.3} 适用条件

使用这个结论之前，先看 @add{1.3}。
```

标记放在内容下方的独立行，引用紧邻的一个完整内容块：文字段落、图片、表格、连续列表、引用块、围栏代码块或独立公式块。代码块和公式块内部的空行会保留。多段内容需要一起预览时，用引用块或 Callout 包起来：

```markdown
> [!note] 适用条件
> 第一段说明。
>
> 第二段说明。

@#add{A.1}

参见 @add{A.1}。
```

空白引用行也要保留 `>`。仅放一个 `@#add{}` 标记就能引用整个引用块，无需给内部每段分别编号。

## 定义与定理

`def` 是 definition 的缩写，`thm` 是 theorem 的缩写。正文显示为「（定义 1.1.1）」「（定理 1.1.1）」，各自编号独立，复用悬停预览、跳转和返回浮标。

单段内容在下方另起一行放标记：

```markdown
**定义 1.1.1** 这里是完整定义。

@#def{1.1.1}

根据 @def{1.1.1}，可以判断……
```

普通换行仍属于同一段落，空行才分隔段落。多段内容、公式和列表需要放在一个完整 Callout 中：

```markdown
> [!theorem] 定理 1.1.1
> 在这些条件下，
>
> $$
> a^2+b^2=c^2
> $$
>
> 可以得到相应结论。

@#thm{1.1.1}
```

### 圈选内容，再确认标记

1. 从定义或定理的首行开头选到末行结尾，包含完整 Markdown 标记。实时预览中难以选中渲染块时，可先显示源码或切到源码模式。
2. 在命令面板或右键菜单执行「**将选中内容设为引用目标**」。
3. 检查类型、编号和完整预览，也可展开查看将写入的 Markdown。插件会从 `**定义 1.1.1**` 这样的开头建议编号，仍可手动修改。
4. 点击「**确认标记**」。单个内容块添加下方标记；多个内容块自动包入 Callout，已有完整 Callout 保持原样。按 Ctrl+Z 可一次撤销。

**桌面端建议快捷键：Alt+D。** 在「Obsidian 设置 → 快捷键」中搜索上述命令，为它绑定按键；如果提示冲突，换一个组合键。插件不预占快捷键。单独按 Alt 或 Alt 拖选不会创建整段引用目标。手机端可把同一命令加入工具栏。

定义的结束位置由选区决定，插件不猜测结束边界，也不扫描全文。选中半行、截断公式或代码块、重复标记已有目标、使用同类型的重复编号时会提示原因。取消不修改笔记；确认窗打开期间笔记或选区发生变化，也不会用旧结果覆盖。

下文的「定义 1.1.4」「定理 1.13a」继续使用「转换选中的引用」处理。已有中英文预设，自定义模板和示例生成模板也支持定义、定理。安装包附有 `定义与定理体验.md`。

## Android 手机端（试用）

手机端使用同一份安装包和引用语法。将 `reference-buoys` 文件夹复制到 Android 笔记库的 `.obsidian/plugins/` 下，再到「设置 → 第三方插件」启用。

| 触摸操作 | 效果 |
| --- | --- |
| 点击引用 | 在屏幕底部打开一个预览面板 |
| 点击预览中的「跳转」 | 跳到原文，留下返回浮标，并收起预览 |
| 点击向下箭头、下滑标题栏，或触碰面板外部 | 收成左下角的小标签 |
| 点击这个小标签 | 恢复原来的预览、滚动位置和上下文展开状态 |
| 点击面板中的 × | 完全关闭预览 |
| 点击返回浮标 | 返回对应阅读位置，并移除这一条浮标 |
| 长按返回浮标 | 打开移除菜单 |

浮标只显示方向和序号，例如 `↑ 1`、`↓ 2`。出发位置在当前阅读位置上方时，浮标放在右上角；在下方时放在右下角。多个浮标分别保留，数量较多时可滚动，不显示上下文摘要。

手机端一次保留一个预览，点击另一个引用会替换当前预览。面板会随横竖屏和可视区域变化调整大小。跳转和返回不会主动聚焦编辑器。

转换旧式引用时，选中文字后执行「转换选中的引用」，也可以将此命令加到 Obsidian 的移动端工具栏。模板和撤销功能与桌面端相同。

已通过手机尺寸下的浏览器触摸测试，**仍需在 Android 真机的 Obsidian 中试用确认**。安装包附有 `手机端体验.md`，可以跟随其中的步骤体验。

浮标用一行显示出发处的原文片段，箭头表示它在当前阅读位置的上方还是下方。悬浮浮标可以看到小节和更完整的文字。新浮标排在最上面，可任选一条返回。

### 浮标与编辑

- 在同一个实时预览编辑器中插入、删除文字，返回位置会随编辑事务一起移动。
- 出发处原文被删除时，浮标明确标记失效，并允许返回附近位置。
- 所有笔记面板共享本次阅读的返回浮标，跨笔记后仍可返回。「清除此篇笔记的返回浮标」只清除从当前笔记出发的浮标。
- **浮标和预览窗不写入磁盘。** 退出 Obsidian、禁用或重载插件后全部清空。设置项会保存。
- 同篇出现重复编号时，预览会列出位置供选择，不会默认跳到第一处。

## 输入与修改

### 把课本里的引用转换过来

在桌面端的实时预览或源码模式中，按住 **Alt**，左键拖选 `式（1.13a）` 这样的完整引用，保持 Alt 按下并松开鼠标，即可转换为 `@{1.13a}`。提前松开 Alt、按 Esc 或离开应用可取消本次转换。

也可以先普通拖选，再执行「引用浮标：转换选中的引用」。在「设置 → 快捷键」中搜索该命令，绑定习惯的按键或鼠标宏。右键菜单中也可执行。插件不预占此命令的快捷键。

| 选中的原文 | 转换结果 |
| --- | --- |
| `式1.13a`、`式(1.13a)`、`（式1.13a）` | `@{1.13a}` |
| `Eq. (1.13a)`、`(1.13a)` | `@{1.13a}` |
| `图1.3`、`Fig. 1.3` | `@fig{1.3}` |
| `表1.3`、`Table 1.3` | `@tab{1.3}` |
| `附A.1` | `@add{A.1}` |
| `定义 1.1.4`、`Definition 1.1.4` | `@def{1.1.4}` |
| `定理 1.13a`、`Thm. (1.13a)` | `@thm{1.13a}` |

- **一次只选一个完整引用，包括它自己的括号。** 选中整句、多处引用、多行内容或多个选区时不会批量替换。
- 一次转换对应一个独立撤销步骤，按 **Ctrl+Z** 恢复原文。
- 代码、独立公式、公式内部的局部选区和已有标准引用保持原样。只有完整选中、仅包含引用编号的行内数学，才能按明确匹配的模板转换。
- 这里只转换引用文字；目标公式仍需要已有 `\tag{编号}`。图、表、附也需要相应的目标标记。
- 在插件设置的「选中转换」里可关闭修饰键拖选，或将 Alt 改为 Ctrl。关闭后仍可使用命令和右键菜单。

#### 为一本书配置模板

1. 打开「设置 → 引用浮标 → 选中转换」，新建模板组，并用书名命名。
2. 点击「添加模板」，选择式、图、表或附，输入模板。例如 `方程[{n}]`，其中 `{n}` 表示编号。
3. 在「试配一段引用」中粘贴原书的例子，例如 `方程［2.13b］`，确认显示 `→ @{2.13b}`。
4. 回到笔记，用 Alt 拖选或快捷键转换。当前模板组会保存，在同一本书的其他笔记中也能继续使用；换书时手动切换模板组。

模板按普通文字填写，无需正则表达式。半角与全角圆括号、方括号可互相匹配，编号附近的空格也会兼容，编号保留大小写。仅此一本书需要特殊规则时，可以关闭该组的「包含常用预设」。多个模板给出不同的有效结果时会让你选择，关闭选择窗即可保持原文。

- `{n}` 提取编号，可以出现多次，各处提取到的编号必须完全一致。
- `{*}` 匹配并忽略变化的内容，也可以匹配空内容。模板仍需至少一个 `{n}`，建议用固定文字或括号界定编号。
- 编号不一致或提取结果不明确时，会提示原因并保留原文。`1-1-4` 和 `1.1.4` 不视为相同编号。

例如，课本中的双链引用可以这样配置：

```text
原文：公式 [[#^eq-1-1-4|(1.1.4)]]
模板：公式 [[#^eq-{*}|({n})]]
结果：@{1.1.4}
```

如果两处都是 `1.1.4`，可以写成 `公式 [[#^eq-{n}|({n})]]`，同时校验两处编号。

有些书用行内数学排版引用编号，这时模板也要保留美元符号：

```text
原文：（$2.1.1$）
模板：（${n}$）
结果：@{2.1.1}
```

请选中**完整引用**，包含外侧括号和完整的 `$...$`；全角、半角括号均可。选中的每个行内数学只能包含模板提取出的同一个编号。`$x+1$` 这类计算式、`$$...$$` 独立公式和只选中公式内部数字的情况仍受保护。插件不会自动剥离美元符号或扫描整篇笔记。

也可以展开「**从示例生成模板**」，粘贴原始引用，填写实际编号并选择类型，点击「生成模板」。生成的模板可以继续修改，试配结果正确后点击「添加到当前模板组」。单个示例无法推断所有变化部分，建议再拿第二处引用试配。生成过程在本地完成，不扫描或修改笔记。

安装包附有 `选中转换练习.md`，可用来尝试以上操作。

### 直接输入标准引用

鼠标宏推荐设置为：**输入 `@{}` → 左方向键**。随后填写编号即可。输入时会列出当前笔记里的引用候选，包括公式预览和所在小节。

编号可以混用数字、点号和字母：输入 `@{1.}` 也能找到 `1.1.b`、`1.1.52c` 和 `1.1.Gauss`。候选优先匹配编号本身，再匹配公式内容，并按编号自然排序；全部匹配项都可滚动查看。搜索不区分大小写，选中后保留原编号及大小写。公式缩略图在候选进入可见区域时加载。

图片、表格和通用附注也可分别设置为 `@fig{}`、`@tab{}`、`@add{}` → 左方向键；候选会按类型筛选。编号标记用 `@#fig{}`、`@#tab{}`、`@#add{}`。

修改已有引用有三种方式：

- 用方向键把光标移进引用，恢复可编辑的源码。
- 按住 Shift 点击引用。
- 右键引用，选择「编辑引用」。

命令面板提供：

- 插入引用 `@{}`
- 插入图片编号标记
- 插入表格编号标记
- 插入通用附注编号标记
- 插入定义编号标记
- 插入定理编号标记
- 将选中内容设为引用目标
- 转换选中的引用
- 返回上一个浮标
- 清除此篇笔记的返回浮标

可以在 Obsidian 的快捷键设置中为这些命令绑定按键。插件不占用预设快捷键。

## 设置

可调整是否默认展开上下文、输入补全和选中转换的模板组。桌面端还可调整悬浮等待时间、预览宽度、返回浮标位置和转换修饰键。颜色跟随 Obsidian 主题。

「**正文长公式横向滚动**」是独立开关，**默认开启**。实时预览和阅读视图中的独立公式超出当前笔记面板宽度时，可以横向滚动；桌面端显示可拖动的滚动条，分屏缩窄后也会随之调整。公式保持原有字号，行内公式和插件预览窗保持原有行为。关闭开关后恢复正文公式原来的样式。

## 试用范围与验证

当前版本主要面向 **Windows 桌面端、Android（试用）和实时预览模式**。编号引用限定在当前笔记，章节双链支持跨笔记。没有自动编号。iOS 尚未测试。

解析、上下文提取、位置跟踪、章节范围、跨笔记返回、选中转换、模板生成、定义/定理目标标记、公式溢出、多编号高亮、递等式聚焦预览、CodeMirror 引用组件和浏览器交互使用自动化测试验证。早期版本已在 Windows Obsidian 中手动试用；0.1.9 的补全改动及 Android 支持仍需在 Obsidian 中试用确认。浏览器组件测试使用简化的 Obsidian API 替身和真实 CodeMirror、MathJax，不能代替 Obsidian 实测。

建议先依次尝试：

1. 悬浮查看示例中的公式、图、表。
2. 固定两个预览并拖动位置。
3. 连续跳转两次，分别点两个浮标返回。
4. 留下浮标后，在笔记顶部插入几行，再返回。
5. 查看多子标号公式组，并尝试修改一个编号、制造重复编号。
6. 重载插件，确认临时浮标已清空。

如果遇到问题，请在 [Issues](https://github.com/Changeuu/ReferenceBuoys/issues) 中提供 Obsidian 版本、使用的主题、最小复现笔记，以及发生问题的操作。公式或图表内容可以换成不涉及隐私的示例。

## 开发

需要 Node.js 24；推荐使用 Windows 开发和验证。

```text
npm ci
npm run check
npm run test:ui
npm run package
```

`test:ui` 在独立无头 Edge 中测试组件，不操作已有浏览器或 Obsidian。需要本机安装 Microsoft Edge。开发测试依赖不会进入发布包。

源码结构：`src/core` 负责解析和位置跟踪，`src/editor.ts` 负责实时预览，`src/ui` 负责预览窗和返回浮标。

仓库维护和发版步骤见 [Git 使用说明](https://github.com/Changeuu/ReferenceBuoys/blob/main/GIT_GUIDE.md)。更新功能或版本时，请同步维护中英文 README。推送到 `main` 会运行基础检查；推送与版本号一致的标签会自动构建并发布安装包。
